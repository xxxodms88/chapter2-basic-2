## 3.1
### 번역
문제 정식화(problem formulation)가 왜 목표 정식화(goal formulation) 다음에 와야 하는지 설명하시오.

### 풀이
문제 정식화란 *어떤 상태와 행동을 고려할지* 정하는 일이다. 무엇이 중요한 상태 구분이고 어떤 수준의 행동을 쓸지는 **목표가 무엇이냐에 따라** 결정된다.
- 예: 목표가 “부쿠레슈티에 가기”라면 상태는 “어느 도시에 있는가”, 행동은 “이웃 도시로 운전하기”면 충분하다. 차선 변경이나 핸들 각도 같은 세부 사항은 이 목표와 무관하므로 추상화해서 버린다.
- 목표 없이 문제를 정식화하면 어떤 세부 사항을 남기고 버릴지 기준이 없어서, 상태 공간이 쓸데없이 커지거나 목표에 필요한 구분을 놓친다.

따라서 먼저 목표를 정해 관심 있는 상태(목표 상태 집합)를 확정하고, 그다음 그 목표에 도달하는 데 필요한 상태와 행동만으로 문제를 정식화한다.

## 3.2
### 번역
다음 각 문제에 대해 완전한 문제 정식화를 제시하시오. 구현할 수 있을 만큼 정확한 정식화를 고르시오.
1. 자물쇠가 달린 유리 상자 여섯 개가 한 줄로 놓여 있다. 처음 다섯 상자에는 각각 다음 상자를 여는 열쇠가 들어 있고, 마지막 상자에는 바나나가 들어 있다. 당신은 첫 번째 상자의 열쇠를 가지고 있고, 바나나를 원한다.
2. ABABAECCEC라는 문자열, 또는 일반적으로 A, B, C, E로 이루어진 임의의 문자열에서 시작한다. 다음 등식을 이용해 문자열을 변형할 수 있다: AC = E, AB = BC, BB = E, 그리고 임의의 $x$에 대해 E$x$ = $x$. 예를 들어 ABBC는 AEC로, 다시 AC로, 다시 E로 변형할 수 있다. 목표는 문자열 E를 만드는 것이다.
3. $n \times n$ 격자의 각 칸은 처음에 칠해지지 않은 바닥이거나 바닥 없는 구덩이다. 당신은 칠해지지 않은 바닥 칸에 서서 시작하며, 발밑의 칸을 칠하거나 인접한 칠해지지 않은 바닥 칸으로 이동할 수 있다. 바닥 전체를 칠하고 싶다.
4. 컨테이너선이 컨테이너를 높이 싣고 항구에 있다. 컨테이너는 13줄이고, 각 줄은 너비 13개, 높이 5개이다. 당신은 배 위 어느 위치로든 이동해서 그 아래의 컨테이너를 집어 부두로 옮길 수 있는 크레인을 조종한다. 배의 짐을 모두 내리고 싶다.

### 풀이
각 문제에 대해 상태, 초기 상태, 행동, 전이 모델, 목표 판정, 경로 비용을 정한다.

**1. 유리 상자**
- 상태: (각 상자의 열림 여부 6비트, 가지고 있는 열쇠 집합, 바나나 보유 여부). 실제로 도달 가능한 상태는 “몇 번째 상자까지 열었는가” $k \in \{0,\dots,6\}$로 충분하다.
- 초기 상태: 상자는 모두 잠김, 열쇠 1을 가짐.
- 행동: Open($i$) — 열쇠 $i$를 가지고 있고 상자 $i$가 잠겨 있을 때. TakeContents($i$) — 열린 상자 $i$의 내용물(열쇠 $i+1$ 또는 바나나)을 꺼냄.
- 전이: Open($i$)이면 상자 $i$가 열림. TakeContents($i$)이면 열쇠 $i+1$(또는 바나나)을 가짐.
- 목표: 바나나를 가짐. 경로 비용: 행동 1회당 1.

**2. 문자열 변형**
- 상태: A, B, C, E로 된 문자열.
- 초기 상태: ABABAECCEC.
- 행동: 문자열 안의 위치 $i$에서 규칙 하나를 적용. 규칙은 AC→E, AB→BC, BB→E, E$x$→$x$ (등식이므로 반대 방향 E→AC 등도 원칙적으로 가능하지만, 문자열을 줄이는 방향만 쓰는 정식화가 탐색에 유리하다).
- 전이: 해당 부분 문자열을 바꾼 새 문자열.
- 목표: 문자열이 정확히 "E". 경로 비용: 적용 1회당 1.

**3. 바닥 칠하기**
- 상태: (내 위치, 각 칸의 칠해짐 여부). 구덩이 위치는 고정된 환경 정보.
- 초기 상태: 주어진 시작 위치, 칠해진 칸 없음.
- 행동: Paint(현재 칸이 안 칠해졌을 때), Move(상/하/좌/우, 이동할 칸이 칠해지지 않은 바닥일 때). 칠한 칸으로는 이동할 수 없다는 점에 주의.
- 목표: 모든 바닥 칸이 칠해짐. 경로 비용: 행동 1회당 1.
- 참고: 칠한 칸에 들어갈 수 없으므로 “칠하고 다음 칸으로 이동”을 반복하는 해밀턴 경로와 같은 구조가 되며, 마지막 칸만 서서 칠할 수 있다. 즉 바닥 칸들을 한 번씩 지나는 경로가 있어야 해가 존재한다.

**4. 컨테이너선**
- 상태: 각 (줄, 열) 위치의 컨테이너 높이 $h_{r,c} \in \{0,\dots,5\}$, 크레인 위치(그리고 크레인이 컨테이너를 들고 있는지).
- 초기 상태: 모든 $h_{r,c} = 5$, 크레인은 정해진 시작 위치.
- 행동: MoveTo($r,c$), PickUp(크레인 아래 맨 위 컨테이너, $h_{r,c} > 0$일 때), DropOnDock.
- 전이: PickUp이면 $h_{r,c}$가 1 감소하고 들고 있음. DropOnDock이면 들고 있지 않음.
- 목표: 모든 $h_{r,c} = 0$. 경로 비용: 크레인 이동 거리 + 집기·내려놓기 시간.

## 3.3
### 번역
목표는 로봇을 미로 밖으로 이끄는 것이다. 로봇은 미로 중앙에서 북쪽을 바라보며 시작한다. 로봇이 북, 동, 남, 서 중 한 방향을 바라보도록 회전시킬 수 있다. 로봇에게 일정 거리를 앞으로 가라고 지시할 수 있으며, 로봇은 벽에 부딪히기 전에 멈춘다.
1. 이 문제를 정식화하시오. 상태 공간은 얼마나 큰가?
2. 미로를 탐색할 때 방향을 바꿔야 하는 곳은 둘 이상의 통로가 만나는 교차점뿐이다. 이 관찰을 이용해 문제를 다시 정식화하시오. 이제 상태 공간은 얼마나 큰가?
3. 미로의 각 지점에서 네 방향 중 어느 쪽으로든 다음 방향 전환 지점에 닿을 때까지 이동할 수 있고, 필요한 행동은 이것뿐이다. 이 행동들로 문제를 다시 정식화하시오. 이제도 로봇의 방향을 추적해야 하는가?
4. 처음 문제를 기술할 때 이미 우리는 행동을 제한하고 세부 사항을 제거하는 방식으로 실제 세계를 추상화했다. 그런 단순화 세 가지를 나열하시오.

### 풀이
1. **정식화**: 상태 = (위치 $(x,y)$, 방향 ∈ {N,E,S,W}). 초기 상태 = (중앙, N). 행동 = Turn(방향), Forward($d$). 목표 = 미로 밖 위치. 위치가 연속 좌표라면 상태는 **무한히 많다**. 미로를 $n$개의 격자 칸으로 이산화하면 $4n$개다.
2. **교차점만 상태로**: 상태 = (교차점 또는 막다른 곳·출구 같은 특별한 지점, 방향). 교차점이 $k$개라면 상태는 $4k$개 정도로 줄어든다. 통로 중간에서는 방향을 바꿀 필요가 없으므로 이 위치들은 상태로 둘 필요가 없다.
3. **“다음 전환 지점까지 이동” 행동**: 상태 = 전환 지점(교차점)만, 행동 = 북/동/남/서 방향으로 다음 전환 지점까지 이동. 이동 방향이 행동에 포함되므로 **방향을 추적할 필요가 없다**. 상태는 $k$개.
4. **이미 한 단순화의 예**:
   - 로봇이 회전이나 이동을 정확히 수행한다고 가정(미끄러짐, 오차 무시).
   - 회전은 정확히 90° 단위의 네 방향만 허용.
   - 로봇의 크기·모양·배터리, 바닥 상태 같은 물리적 세부 사항 무시.
   - 미로의 지도를 알고 있고 벽에서 정확히 멈춘다고 가정.

## 3.4
### 번역
각 칸을 빨강 또는 파랑으로 칠할 수 있는 $9 \times 9$ 격자가 있다. 격자는 처음에 모두 파랑이지만, 어느 칸의 색이든 몇 번이고 바꿀 수 있다. 격자를 아홉 개의 $3 \times 3$ 부분 정사각형으로 나눈다고 할 때, 각 부분 정사각형은 한 가지 색으로 통일되고 이웃한 부분 정사각형끼리는 색이 다르기를 원한다.
1. 이 문제를 단순한 방식으로 정식화하시오. 상태 공간의 크기를 계산하시오.
2. 한 칸은 한 번만 칠하면 된다. 다시 정식화하고 상태 공간의 크기를 계산하시오. 이 문제에서 너비 우선 그래프 탐색은 (a)보다 빠르게 동작하겠는가? 반복 심화 트리 탐색은 어떤가?
3. 목표를 생각하면 각 부분 정사각형이 한 색으로 칠해진 경우만 고려하면 된다. 문제를 다시 정식화하고 상태 공간의 크기를 계산하시오.
4. 이 문제의 해는 몇 개인가?
5. (b)와 (c)는 원래 문제 (a)를 차례로 추상화한 것이다. (c) 문제의 해를 (b) 문제의 해로, (b) 문제의 해를 (a) 문제의 해로 바꾸는 방법을 제시할 수 있는가?

### 풀이
1. 상태 = 81칸 각각의 색. 행동 = 아무 칸 하나의 색 바꾸기(81가지). 목표 = 조건을 만족하는 색칠. 상태 공간 크기 $2^{81} \approx 2.4\times10^{24}$.
2. 상태 = 각 칸이 (아직 안 칠함=파랑 그대로, 빨강으로 칠함). 한 칸을 한 번만 칠하면 되므로 행동 = 아직 안 칠한 칸 하나를 빨강으로 칠하기. 가능한 상태의 집합은 여전히 “빨간 칸의 부분집합”이라 $2^{81}$개다.
   - **너비 우선 그래프 탐색**: 탐색하는 상태 수가 같으므로 크게 빨라지지 않는다. (행동 수는 줄어 약간의 이득은 있다.)
   - **반복 심화 트리 탐색**: 크게 이득이다. (a)에서는 같은 칸을 칠했다 되돌리는 경로가 무한히 있어 트리가 무한하지만, (b)에서는 경로 길이가 81 이하로 제한되고 되돌리기가 없어 불필요한 반복이 줄어든다. (그래도 같은 집합에 도달하는 순서가 여러 가지라 중복은 남는다. 칸을 정해진 순서로만 칠하도록 하면 더 줄일 수 있다.)
3. 상태 = 9개 부분 정사각형 각각의 색. 크기 $2^9 = 512$.
4. 부분 정사각형 $3\times3$ 배열이 이웃끼리 다른 색이어야 하므로 체스판 무늬만 가능하다. 왼쪽 위가 빨강인 경우와 파랑인 경우의 **2개**. (512가지를 모두 검사한 결과도 2개다.)
5. **변환**: (c)의 해에서 빨간 부분 정사각형마다 그 안의 9칸을 빨강으로 칠하는 행동 9개를 나열하면 (b)의 해가 된다. (b)의 각 “칸을 빨강으로 칠함” 행동은 (a)의 “그 칸의 색을 바꿈” 행동과 같으므로 (b)의 해는 그대로 (a)의 해다(처음에 모두 파랑이므로).

## 3.5
### 번역
두 친구가 지도(예: [교재 참조: 루마니아 지도]) 위의 서로 다른 도시에 산다고 하자. 매 턴마다 두 친구를 각각 지도의 이웃 도시로 동시에 이동시킬 수 있다. 도시 $i$에서 이웃 도시 $j$로 이동하는 데 걸리는 시간은 두 도시 사이의 도로 거리 $d(i,j)$와 같지만, 매 턴 먼저 도착한 친구는 다른 친구가 도착할 때까지(그리고 휴대전화로 먼저 온 친구에게 연락할 때까지) 기다려야 다음 턴을 시작할 수 있다. 두 친구가 가능한 한 빨리 만나기를 원한다.
1. 이 탐색 문제의 자세한 정식화를 작성하시오. (형식적인 표기법을 정의하면 도움이 될 것이다.)
2. $D(i,j)$를 도시 $i$와 $j$ 사이의 직선 거리라고 하자. 다음 휴리스틱 함수 중 허용 가능한(admissible) 것은 무엇인가? (i) $D(i,j)$, (ii) $2\cdot D(i,j)$, (iii) $D(i,j)/2$.
3. 완전히 연결된 지도인데도 해가 존재하지 않는 경우가 있는가?
4. 모든 해가 한 친구로 하여금 같은 도시를 두 번 방문하도록 요구하는 지도가 있는가?

### 풀이
1. **정식화**
   - 상태: 두 친구의 위치 쌍 $(i, j)$.
   - 초기 상태: $(i_0, j_0)$.
   - 행동: $(i, j)$에서 이웃 도시 쌍 $(i', j')$로 동시에 이동. ($i' \in N(i)$, $j' \in N(j)$, $N$은 이웃 집합.)
   - 전이: $(i, j) \to (i', j')$.
   - 단계 비용: $\max(d(i,i'), d(j,j'))$ — 늦게 도착하는 사람을 기다리므로.
   - 목표 판정: $i = j$ (같은 도시에서 만남).
2. 남은 직선 거리 $D(i,j)$를 두 사람이 함께 줄여 나간다. 매 턴 두 사람이 줄일 수 있는 거리의 합은 최대 $d(i,i') + d(j,j') \le 2\max(\cdot)$ = 2 × 단계 비용. 따라서 최적 비용 $C^* \ge D(i,j)/2$.
   - (iii) $D(i,j)/2$: **허용 가능.**
   - (i) $D(i,j)$: 허용 불가능. 예: 두 사람이 서로를 향해 직선 도로로 연결된 두 도시에 있고 가운데 도시에서 만나면, 비용은 $D/2$인데 휴리스틱은 $D$로 과대평가한다.
   - (ii) $2D$: 당연히 허용 불가능.
3. **있다.** 예: 두 도시 A, B만 도로 하나로 연결된 지도에서 두 친구가 A와 B에 있으면, 매 턴 둘 다 반드시 이동해야 하므로 (B, A) ↔ (A, B)를 영원히 오가며 만나지 못한다. 그래프가 이분 그래프(bipartite)이고 두 사람이 서로 다른 쪽에 있으면 항상 해가 없다.
4. **있다.** 3번에서 보았듯 두 사람 사이의 경로 길이(간선 수)가 홀수이면 직선 경로만으로는 만날 수 없고, 누군가 홀수 길이 고리를 돌아 홀짝을 바꿔야 한다. 예: 일렬 지도 A–B–C–D에서 두 친구가 A와 D에 있고(거리 3, 홀수), C에 삼각형 고리 C–E–F–C가 붙어 있다고 하자. 매 턴 둘 다 움직여야 하므로 일렬 부분만으로는 늘 홀수 거리를 유지해 만나지 못한다. 만나려면 한 사람이 삼각형을 한 바퀴 돌아야 하고, 그러면 고리의 입구 도시 C를 들어갈 때와 나올 때 두 번 방문하게 된다. 따라서 모든 해가 한 친구로 하여금 같은 도시를 두 번 방문하도록 요구하는 지도가 존재한다.

### 번역
8-퍼즐의 상태들이 서로소인 두 집합으로 나뉘어서, 같은 집합 안의 어떤 상태에서든 다른 어떤 상태로도 도달할 수 있지만 다른 집합의 상태로는 도달할 수 없음을 보이시오. (힌트: Berlekamp 외(1982)를 보라.) 주어진 상태가 어느 집합에 속하는지 판정하는 절차를 고안하고, 이것이 무작위 상태를 생성할 때 왜 유용한지 설명하시오.

### 풀이
**불변량**: 빈칸을 제외한 8개 타일을 행 우선 순서로 읽어 수열로 만들고, 그 수열의 **역전 쌍의 수**(앞에 있는 수가 뒤의 수보다 큰 쌍의 개수)의 홀짝성을 본다.
- 빈칸을 좌우로 움직이면 타일 순서가 바뀌지 않으므로 역전 수가 그대로다.
- 빈칸을 위아래로 움직이면 한 타일이 다른 두 타일을 건너뛰어 이동한다(3×3 격자에서 한 행 차이는 순서상 2칸). 그러면 역전 수가 $+2$, $0$, $-2$ 중 하나만큼 바뀐다.

또한 같은 홀짝성을 가진 상태끼리는 모두 서로 도달 가능하다는 것이 알려져 있다(각 집합이 $9!/2 = 181{,}440$개 상태). 증명은 3-사이클 회전으로 임의의 짝순열을 만들 수 있음을 보이는 방식으로 한다.

**판정 절차**: 타일 수열의 역전 수를 세어 짝수인지 홀수인지 본다. $O(n^2)$ (또는 병합 정렬 방식으로 $O(n\log n)$).

**유용성**: 무작위 시작 상태를 그냥 섞어서 만들면 절반은 목표에서 도달 불가능해 탐색이 헛돈다. 생성한 배치의 홀짝성을 확인해 목표와 같은 집합에 속하는 것만 쓰면(아니면 타일 두 개를 바꿔 홀짝성을 맞추면) 항상 해가 있는 문제를 만들 수 있다.

## 3.7
### 번역
[교재: nqueens-page]에 나온 “효율적인” 점진적(incremental) 정식화를 사용하는 $n$-퀸 문제를 생각하자. 상태 공간에 적어도 $\sqrt[3]{n!}$개의 상태가 있는 이유를 설명하고, 전수 탐색이 가능한 가장 큰 $n$을 추정하시오. (힌트: 어떤 열에서든 퀸 하나가 공격할 수 있는 칸의 최대 수를 생각해 분기 계수의 하한을 유도하라.)

### 풀이
효율적 정식화: 가장 왼쪽 빈 열에 퀸을 놓되, 이미 놓인 퀸들에게 공격받지 않는 칸에만 놓는다.

- 이미 놓인 퀸 하나는 다른 한 열에서 **최대 3칸**(같은 행, 두 대각선)만 공격한다.
- $k$개의 퀸이 놓였을 때 $(k+1)$번째 열에서 공격받는 칸은 최대 $3k$개이므로, 안전한 칸은 적어도 $n - 3k$개다.
- 따라서 상태 수는 적어도
  $$S \ge \prod_{k=0}^{\lfloor n/3 \rfloor} (n - 3k) = n(n-3)(n-6)\cdots.$$
- 이 곱을 세 번 곱하면 $\big(n(n-3)(n-6)\cdots\big)^3 \ge n(n-1)(n-2)\cdot(n-3)(n-4)(n-5)\cdots = n!$ 이다(각 인수 $n-3k$가 $n-3k$, $n-3k-1$, $n-3k-2$ 이상이므로). 즉 $S \ge \sqrt[3]{n!}$.

**전수 탐색 가능한 $n$ 추정**: 초당 약 $10^{7}$~$10^{8}$개 상태를 생성한다고 보고, 몇 시간 안에 탐색 가능한 상태가 $10^{12}$개 정도라 하면 $\sqrt[3]{n!} \approx 10^{12}$, 즉 $n! \approx 10^{36}$ 이다. $30! \approx 2.7\times10^{32}$, $33! \approx 8.7\times10^{36}$ 이므로 **$n \approx 30$ 정도**가 한계다. (하한이므로 실제로는 더 작은 $n$에서 어려워진다. 실제 백트래킹 탐색은 가지치기 덕분에 이보다 훨씬 적은 상태만 보지만, “모든 해를 찾는” 전수 탐색은 $n=27$ 근처가 현재 기록 수준이다.)

2. 최단 경로가 장애물에 닿지 않는 구간에서 휘어져 있다면, 그 부분을 직선으로 펴서 더 짧게 만들 수 있다(삼각 부등식). 따라서 최단 경로는 선분들로 이루어지고, 방향이 바뀌는 곳은 장애물에 막힌 곳뿐이다. 볼록 다각형에서 경로가 꺾일 수 있는 곳은 꼭짓점뿐이다(변 중간에서 꺾으면 꼭짓점 쪽으로 당겨 더 줄일 수 있다).

   - `RESULT(v, a)`: $v + a$.
   - `GOAL-TEST(v)`: $v$ = 목표점.
   - `STEP-COST(v, a, w)`: $\lVert a \rVert$ (유클리드 거리).
   - `h(v)`: $\lVert \text{목표} - v \rVert$, 직선 거리. 어떤 경로도 직선보다 짧을 수 없으므로 허용 가능하고, 삼각 부등식 때문에 일관적이기도 하다.
   - 가시성 판정: 선분 $vw$가 어떤 다각형의 변과 (끝점이 아닌 곳에서) 교차하거나 다각형 내부를 지나는지 검사.
4. **성능**: 직선 거리 휴리스틱을 쓰는 A*는 일관적이므로 최적 경로를 찾고, 보통 목표 방향의 꼭짓점들만 확장해 효율적이다. 균일 비용 탐색은 모든 방향으로 고르게 퍼져 더 많은 노드를 확장한다. 장애물이 목표를 가로막는 “함정” 형태일수록 A*의 이득이 줄어든다. 전체 비용은 대개 탐색보다 가시성 그래프를 만드는 계산(단순 구현은 $O(V^3)$)이 지배한다.

4. 경로 탐색 같은 영역에서도 큰 음의 비용을 가진 행동을 쉽게 상상할 수 있다. 예를 들어 어떤 도로 구간은 경치가 너무 아름다워서 시간과 연료라는 일반적인 비용을 훨씬 넘어설 수 있다. 상태 공간 탐색의 맥락에서, 사람이 경치 좋은 순환 도로를 끝없이 돌지 않는 이유를 정확한 용어로 설명하고, 인공 에이전트도 순환을 피할 수 있도록 경로 탐색의 상태 공간과 행동을 정의하는 방법을 설명하시오.
5. 단계 비용이 순환을 일으키는 실제 영역을 생각할 수 있는가?

### 풀이
1. 아직 탐색하지 않은 어떤 행동이든 임의로 큰 음의 비용을 가질 수 있다. 그러면 지금까지 찾은 경로보다 훨씬 싼 경로가 그 미탐색 부분을 거쳐 존재할 수 있으므로, 상태 공간의 모든 부분을 보기 전까지는 어떤 해도 최적이라고 확신할 수 없다.
2. **트리**: 깊이가 유한하고 단계 비용 하한이 $c$이면, 깊이 $d$ 아래 남은 경로 비용은 적어도 $c\cdot(\text{남은 깊이})$이다. 최대 깊이를 알면 그만큼 가지치기를 할 수 있어 도움이 된다. 하지만 깊이가 무한하면 남은 비용의 하한이 $-\infty$가 되어 여전히 전체를 봐야 한다. **그래프**: 순환이 있으면 음의 비용 고리를 무한히 돌아 비용을 $-\infty$로 만들 수 있으므로 최적 해 자체가 존재하지 않을 수 있다. 상수 하한만으로는 해결되지 않는다.
3. 그런 고리를 한 번 돌 때마다 총비용이 줄어들므로, 최적 행동은 **그 고리를 영원히 도는 것**이다. 최적 해가 존재하지 않는다(비용이 하한 없이 줄어듦).
4. 사람에게 경치의 가치는 반복할수록 줄어든다(두 번째, 세 번째 바퀴는 처음만큼 즐겁지 않다). 즉 단계 비용이 현재 위치만이 아니라 **과거 이력**에 의존한다. 상태 공간 용어로 말하면, 사람의 실제 상태는 “위치”만이 아니라 “이미 본 경치”를 포함하고, 그 상태에서는 같은 도로의 비용이 더 이상 음수가 아니다.
   - 인공 에이전트를 위한 정의: 상태 = (현재 위치, 이미 지나간 경치 도로 구간 집합). 경치 보너스(음의 비용)는 그 구간을 처음 지날 때만 주고 이후에는 일반 비용만 주면, 음의 비용 고리가 사라져 순환이 이득이 아니게 된다.
5. 예: 금융 차익 거래. 통화를 A→B→C→A로 교환할 때 환율 불일치로 매번 이익이 나면(음의 비용 고리) 계속 반복하는 것이 최적이다. 실제로는 거래 비용과 시장 반응 때문에 고리가 곧 사라진다. 또 다른 예로 보상이 계속 들어오는 게임 루프(같은 적을 반복 처치해 점수를 쌓기)가 있다.

## 3.11
### 번역
[교재 참조: 선교사와 식인종 문제]는 보통 다음과 같이 기술된다. 선교사 세 명과 식인종 세 명이 강 한쪽에 있고, 한두 명을 태울 수 있는 배 한 척이 있다. 어떤 곳에서도 선교사 무리가 그곳의 식인종보다 수가 적어지는 일이 없게 하면서, 모두를 반대편으로 건너가게 하는 방법을 찾아라. 이 문제는 분석적 관점에서 문제 정식화를 다룬 최초의 논문 [Amarel, 1968]의 주제였기 때문에 AI에서 유명하다.
1. 올바른 해를 보장하는 데 필요한 구분만 하도록 문제를 정확히 정식화하시오. 전체 상태 공간의 그림을 그리시오.
2. 적절한 탐색 알고리즘을 사용해 문제를 구현하고 최적으로 푸시오. 반복 상태를 검사하는 것이 좋은 생각인가?
3. 상태 공간이 이렇게 단순한데도 사람들이 이 퍼즐을 푸는 데 어려움을 겪는 이유는 무엇이라고 생각하는가?

### 풀이
1. **정식화**
   - 상태: $(m, c, b)$ = 출발 쪽 강변의 선교사 수, 식인종 수, 배가 출발 쪽에 있으면 1 아니면 0. (사람은 개별적으로 구분할 필요가 없다.)
   - 초기 상태 $(3,3,1)$, 목표 상태 $(0,0,0)$.
   - 행동: 배에 태울 사람 조합 (선교사, 식인종) ∈ {(1,0), (2,0), (0,1), (0,2), (1,1)}. 배가 있는 쪽에서 반대쪽으로 이동.
   - 제약: 양쪽 강변 모두에서 선교사가 0명이거나 선교사 수 ≥ 식인종 수.
   - 경로 비용: 건너는 횟수.
   - 제약을 만족하는 상태는 모두 **20개**이고(그중 실제로 도달 가능한 것은 더 적다), 그림은 $m$을 세로축, $c$를 가로축으로 놓고 $b=1$, $b=0$ 두 판에 상태를 배치한 뒤 가능한 건너기로 잇는다.
2. **풀이**: 너비 우선 탐색(모든 단계 비용이 1이므로 최적)으로 찾은 최단 해는 **11번 건너기**이다.

   | 단계 | 건너는 사람 | 상태 $(m,c,b)$ |
   |---|---|---|
   | 0 | — | (3,3,1) |
   | 1 | 식인종 2명 → | (3,1,0) |
   | 2 | ← 식인종 1명 | (3,2,1) |
   | 3 | 식인종 2명 → | (3,0,0) |
   | 4 | ← 식인종 1명 | (3,1,1) |
   | 5 | 선교사 2명 → | (1,1,0) |
   | 6 | ← 선교사 1명, 식인종 1명 | (2,2,1) |
   | 7 | 선교사 2명 → | (0,2,0) |
   | 8 | ← 식인종 1명 | (0,3,1) |
   | 9 | 식인종 2명 → | (0,1,0) |
   | 10 | ← 선교사 1명 | (1,1,1) |
   | 11 | 선교사 1명, 식인종 1명 → | (0,0,0) |

   (10~11단계를 “← 식인종 1명 → (0,2,1)”, “식인종 2명 → → (0,0,0)”으로 해도 같은 11단계 해가 된다.)

   **반복 상태 검사는 좋은 생각이다.** 모든 행동이 되돌릴 수 있어서(배로 다시 건너면 이전 상태) 검사하지 않으면 트리 탐색이 같은 상태를 무한히 오가며 크게 낭비한다.
3. 사람이 어려워하는 이유: 해의 중간(6단계)에 선교사와 식인종을 **함께 되돌려 보내는**, 목표에서 멀어지는 것처럼 보이는 행동이 필요하다. 사람은 “목표에 가까워지는” 행동을 선호하는 경향(언덕 오르기식 휴리스틱)이 있어 이런 수를 떠올리기 어렵다. 또 상태를 머릿속에 정리해 두지 않으면 이미 가 본 상태를 반복하게 된다.

## 3.12
### 번역
다음 용어를 자신의 말로 정의하시오: 상태, 상태 공간, 탐색 트리, 탐색 노드, 목표, 행동, 전이 모델, 분기 계수.

### 풀이
- **상태(state)**: 문제를 푸는 데 필요한 만큼 세계의 상황을 표현한 것.
- **상태 공간(state space)**: 초기 상태에서 어떤 행동 열로든 도달할 수 있는 모든 상태의 집합. 상태를 노드, 행동을 간선으로 하는 그래프로 볼 수 있다.
- **탐색 트리(search tree)**: 초기 상태를 뿌리로 하여, 탐색 중에 생성한 행동 열(경로)들을 트리 형태로 펼친 것. 같은 상태가 여러 노드로 나타날 수 있다.
- **탐색 노드(search node)**: 탐색 트리의 한 노드. 상태뿐 아니라 부모 노드, 그 노드를 만든 행동, 경로 비용 $g(n)$, 깊이 등의 정보를 담는 자료 구조.
- **목표(goal)**: 에이전트가 도달하려는 상태(또는 상태 집합). 목표 판정 함수로 확인한다.
- **행동(action)**: 어떤 상태에서 에이전트가 할 수 있는 일. `ACTIONS(s)`는 상태 $s$에서 가능한 행동의 집합이다.
- **전이 모델(transition model)**: 각 행동이 상태를 어떻게 바꾸는지 기술하는 것. `RESULT(s, a)`는 상태 $s$에서 행동 $a$를 하면 도달하는 상태다.
- **분기 계수(branching factor)**: 한 노드가 가지는 자식(후속자) 수. 보통 최대값 $b$ 또는 평균값을 쓴다.

## 3.13
### 번역
세계 상태(world state), 상태 기술(state description), 탐색 노드(search node)의 차이는 무엇인가? 이런 구분은 왜 유용한가?

### 풀이
- **세계 상태**: 실제 세계의 모든 세부 사항을 포함한 실제 상황. 무한히 자세하다.
- **상태 기술**: 그 세계 상태를 문제 해결에 필요한 만큼만 추상화해서 표현한 것(예: “아라드에 있다”). 서로 다른 많은 세계 상태가 같은 상태 기술에 대응한다.
- **탐색 노드**: 탐색 알고리즘이 쓰는 자료 구조로, 상태 기술에 더해 그 상태에 도달한 *경로*에 대한 정보(부모, 행동, 경로 비용, 깊이)를 담는다. 같은 상태에 서로 다른 경로로 도달하면 서로 다른 노드가 된다.

**유용성**: 세계 상태와 상태 기술을 구분해야 올바른 추상화(무엇을 버릴지)를 할 수 있다. 상태와 노드를 구분해야 같은 상태에 대한 여러 경로를 다루고, 반복 상태 검사(그래프 탐색)나 경로 재구성을 올바르게 구현할 수 있다.

## 3.14
### 번역
[교재 참조: Go(Sibiu) 같은 행동]은 실제로는 차에 시동을 걸고, 브레이크를 풀고, 앞으로 가속하는 등의 더 세밀한 행동의 긴 열로 이루어져 있다. 이런 복합 행동을 쓰면 해의 단계 수가 줄어들어 탐색 시간이 줄어든다. 이를 논리적 극단까지 밀어붙여, 가능한 모든 행동 열마다 초복합(super-composite) 행동을 만든다고 하자. 그러면 모든 문제 인스턴스는 [교재 참조: 예를 들어 Go(Sibiu)Go(Rimnicu Vilcea)Go(Pitesti)Go(Bucharest)] 같은 초복합 행동 하나로 풀린다. 이 정식화에서 탐색이 어떻게 동작할지 설명하시오. 이것은 문제 해결 속도를 높이는 실용적인 방법인가?

### 풀이
이 정식화에서 탐색 트리의 깊이는 1이고, 뿌리의 자식은 *가능한 모든 행동 열*에 대응한다. 탐색은 이 초복합 행동들을 하나씩 생성해 결과 상태가 목표인지 검사하는 것이 된다.

**실용적이지 않다.** 분기 계수가 원래 문제의 모든 경로 수만큼(무한할 수도 있음) 커지므로, 깊이가 줄어든 효과가 사라진다. 결국 원래 문제의 모든 경로를 열거하는 것과 같은 일을 하고, 그보다 나쁘게는 공유되는 앞부분 경로를 재사용하지 못한다(원래 트리에서는 공통 접두사를 한 번만 생성한다). 탐색의 어려움은 사라지지 않고 “어떤 행동을 고를까”로 옮겨갈 뿐이다. 유용한 것은 자주 쓰이는 일부 행동 열만 매크로 행동으로 만드는 것이다.

## 3.15
### 번역
유한한 상태 공간은 항상 유한한 탐색 트리로 이어지는가? 트리 모양인 유한 상태 공간은 어떤가? 어떤 유형의 상태 공간이 항상 유한한 탐색 트리로 이어지는지 더 정확하게 말할 수 있는가? ([교재 참조: Bender], 1996에서 변형)

### 풀이
- **아니다.** 유한 상태 공간이라도 순환(cycle)이 있으면 트리 탐색은 그 고리를 무한히 따라갈 수 있어 탐색 트리가 무한하다. 예: 행동을 되돌릴 수 있는 문제(아라드 ↔ 시비우).
- **트리 모양의 유한 상태 공간**은 순환이 없고 각 상태에 이르는 경로가 하나뿐이므로 탐색 트리가 상태 공간과 같고, 유한하다.
- **정확한 조건**: 상태 공간이 **유한한 방향성 비순환 그래프(DAG)** 이면 탐색 트리는 유한하다. 순환이 없으므로 모든 경로의 길이가 상태 수 이하이고, 경로의 수도 유한하기 때문이다. (DAG에서는 같은 상태에 여러 경로로 도달해 탐색 트리가 상태 공간보다 지수적으로 클 수는 있다.) 반대로 초기 상태에서 도달할 수 있는 순환이 하나라도 있으면 탐색 트리는 무한하다.

## 3.16
### 번역
[교재 참조: GRAPH-SEARCH]가 [교재 참조: 그래프 분리 속성 그림]에 나타난 그래프 분리 속성을 만족함을 증명하시오. (힌트: 먼저 이 속성이 시작할 때 성립함을 보이고, 알고리즘의 한 반복 전에 성립하면 반복 후에도 성립함을 보여라.) 이 속성을 위반하는 탐색 알고리즘을 기술하시오.

### 풀이
**분리 속성**: 초기 상태에서 아직 탐색하지 않은(unexplored) 어떤 상태로 가는 모든 경로는 반드시 **프런티어**의 어떤 상태를 지난다. 즉 프런티어가 탐색된 영역과 미탐색 영역을 나눈다.

**증명(귀납법)**
- **시작**: 프런티어 = {초기 상태}, 탐색 집합 = ∅. 초기 상태에서 출발하는 모든 경로는 초기 상태(프런티어)를 지나므로 성립한다.
- **유지**: 한 반복에서 프런티어의 노드 $n$을 꺼내 탐색 집합에 넣고, $n$의 후속자 중 탐색 집합이나 프런티어에 없는 것을 프런티어에 넣는다. 반복 전에 속성이 성립했다고 하자. 미탐색 상태 $s$로 가는 임의의 경로 $P$를 생각한다.
  - $P$가 $n$이 아닌 프런티어 노드를 지났다면, 그 노드는 여전히 프런티어에 있으므로 성립.
  - $P$가 지나는 프런티어 노드가 $n$뿐이었다면, $P$에서 $n$ 바로 다음 상태 $s'$는 $n$의 후속자다. $s'$는 이제 프런티어에 들어갔거나(새로 추가), 이미 프런티어에 있었거나, 탐색 집합에 있다. 탐색 집합에 있었다면 $P$의 그 뒷부분을 다시 같은 논리로 적용한다(탐색된 상태에서 미탐색 상태로 가려면 결국 프런티어를 지나야 한다는 귀납 가정). 따라서 $P$는 새 프런티어의 노드를 지난다.
  - 따라서 반복 후에도 성립한다. ∎

**위반하는 알고리즘의 예**: 노드를 확장할 때 후속자 중 일부만 프런티어에 넣고 나머지를 버리는 알고리즘(예: 빔 탐색, 혹은 탐색 집합에 넣은 노드의 후속자를 “이미 본 적이 있어서” 잘못 버리는 구현). 또는 프런티어에서 노드를 꺼낼 때 그 노드를 확장하지 않고 탐색 집합에 넣는 버그가 있는 알고리즘. 이런 경우 미탐색 상태로 가는 경로가 프런티어를 거치지 않게 되어 완전성을 잃는다.

### 번역
8-퍼즐을 위한 [교재 참조: 후속자/RESULT] 함수를 두 가지 버전으로 구현하시오. 하나는 부모 노드 $s$의 자료 구조를 복사해서 수정하고, 다른 하나는 부모 상태를 직접 수정한다(필요할 때 수정을 되돌린다). 이 함수들을 사용하는 반복 심화 깊이 우선 탐색을 각각 작성하고 성능을 비교하시오.

### 풀이
```python
import time

GOAL = (1, 2, 3, 4, 5, 6, 7, 8, 0)
MOVES = {0: (1, 3), 1: (0, 2, 4), 2: (1, 5), 3: (0, 4, 6), 4: (1, 3, 5, 7),
         5: (2, 4, 8), 6: (3, 7), 7: (4, 6, 8), 8: (5, 7)}

# 버전 1: 부모 상태를 복사해서 새 상태를 만든다
def successors_copy(state):
    z = state.index(0)
    for t in MOVES[z]:
        s = list(state); s[z], s[t] = s[t], s[z]
        yield tuple(s)

def dls_copy(state, limit, prev=None):
    if state == GOAL: return True
    if limit == 0: return False
    return any(dls_copy(c, limit - 1, state) for c in successors_copy(state) if c != prev)

# 버전 2: 하나의 배열을 제자리에서 바꾸고, 돌아올 때 되돌린다
def dls_inplace(board, z, limit, prev_z=-1):
    if board == list(GOAL): return True       # 실제 구현은 맞은 타일 수를 증분 갱신하면 더 빠름
    if limit == 0: return False
    for t in MOVES[z]:
        if t == prev_z: continue
        board[z], board[t] = board[t], board[z]          # 수정
        if dls_inplace(board, t, limit - 1, z): return True
        board[z], board[t] = board[t], board[z]          # 되돌리기
    return False

def ids(start, inplace):
    for d in range(32):
        ok = dls_inplace(list(start), start.index(0), d) if inplace else dls_copy(start, d)
        if ok: return d

start = (8, 6, 7, 2, 5, 4, 3, 0, 1)   # 예시
for inplace in (False, True):
    t = time.time(); d = ids(start, inplace)
    print('제자리 수정' if inplace else '복사', d, f'{time.time() - t:.2f}s')
```

**예상되는 결과와 해석**: 두 버전은 같은 노드를 같은 순서로 방문하므로 해와 확장 노드 수는 같다. 차이는 노드당 비용이다. 복사 버전은 노드마다 새 튜플(9개 원소)을 할당하므로 메모리 할당·해제 비용이 들고, 제자리 수정 버전은 교환 두 번으로 끝나 노드당 비용이 작다. 반복 심화 탐색은 같은 노드를 반복해서 생성하므로 이 상수 차이가 전체 시간에 그대로 곱해진다. 일반적으로 제자리 수정 버전이 몇 배 빠르다(정확한 배율은 언어와 구현에 따라 다르므로 직접 측정해 보고할 것). 대신 제자리 수정은 되돌리기를 빠뜨리면 버그가 생기기 쉽다.

1. **최적성**: 한계가 $L$인 반복은 경로 비용 $\le L$인 모든 노드를 (깊이 우선으로) 탐색한다. 새 한계는 이전에 버려진 비용 중 최솟값이므로, 어떤 경로 비용 값도 건너뛰지 않는다. 즉 한계는 실제로 존재하는 경로 비용들을 오름차순으로 하나씩 지난다. 최적 해 비용이 $C^*$이면, 한계가 처음으로 $C^*$ 이상이 되는 반복은 한계가 정확히 $C^*$인 반복이고(그 사이 값이 없으므로), 이 반복에서 비용 $C^*$인 목표가 발견된다. 그보다 앞선 반복에서는 한계가 $C^*$ 미만이라 목표를 찾지 못한다(그런 목표가 있었다면 최적 비용이 더 작았을 것이다). 따라서 처음 찾은 해는 최적이다. (단, 같은 반복 안에서 비용이 더 큰 목표를 먼저 반환하지 않도록, 반환하는 목표의 비용이 한계와 같은지 확인하거나 반복 안의 최소 비용 목표를 반환한다.)
2. 단위 비용이면 경로 비용 = 깊이이므로 한계가 0, 1, 2, …, $d$로 증가한다. **$d+1$번** 반복한다(반복 심화와 같다).
3. 비용이 연속값이면 서로 다른 경로 비용이 모두 다를 수 있어, 반복마다 한계가 노드 하나만큼만 늘어날 수 있다. 최악의 경우 반복 수는 비용이 $C^*$ 이하인 **노드의 수**만큼이다. 단계 비용이 최소 $\epsilon$이므로 그런 노드의 깊이는 $C^*/\epsilon$ 이하이고, 반복 수는 최악의 경우 $O(b^{1 + \lfloor C^*/\epsilon \rfloor})$이다. 각 반복의 비용까지 합하면 전체 비용은 그 제곱 정도가 되어 매우 나쁘다.
4. **구현과 비교의 요점**
   ```python
   def iterative_lengthening(problem):
       limit = 0
       while True:
           next_limit = float('inf')
           stack = [(problem.initial, 0)]
           while stack:
               s, g = stack.pop()
               if problem.is_goal(s) and g <= limit: return s, g
               for s2, cost in problem.successors(s):
                   g2 = g + cost
                   if g2 > limit: next_limit = min(next_limit, g2)
                   else: stack.append((s2, g2))
           if next_limit == float('inf'): return None
           limit = next_limit
   ```
   - **8-퍼즐(단위 비용)**: 반복 수가 해의 깊이 + 1이라 반복 심화와 같고, 균일 비용 탐색보다 시간은 조금 더 들지만 메모리는 훨씬 적다.
   - **TSP(실수 거리)**: 경로 비용이 거의 모두 다르므로 반복이 노드 하나씩만 늘어나 반복 수가 폭발하고, 균일 비용 탐색보다 훨씬 느리다. 이를 막으려면 한계를 “버려진 비용의 최솟값”이 아니라 일정 비율(예: 버려진 비용 분포의 일부를 포함하도록) 늘리는 변형을 쓰지만, 그러면 최적성이 근사로 바뀐다.

## 3.22
### 번역
반복 심화 탐색이 깊이 우선 탐색보다 훨씬 나쁘게 동작하는 상태 공간을 기술하시오(예: $O(n^{2})$ 대 $O(n)$).

### 풀이
분기 계수가 1인 **일렬 사슬** 상태 공간: $s_0 \to s_1 \to \cdots \to s_n$, 목표는 $s_n$ 하나.
- **깊이 우선 탐색**: 사슬을 한 번 따라가 $n+1$개 노드를 확장한다. $O(n)$.
- **반복 심화 탐색**: 깊이 한계 $0, 1, \dots, n$마다 처음부터 다시 따라가므로 $\sum_{k=0}^{n}(k+1) = \frac{(n+1)(n+2)}{2} = O(n^2)$.

반복 심화가 효율적인 이유는 분기 계수가 커서 마지막 층의 노드가 대부분을 차지하기 때문인데, 분기 계수가 1이면 그 이점이 사라진다. 더 일반적으로는 목표가 깊고 트리가 거의 가지를 치지 않는 공간이면 같은 현상이 나타난다.

## 3.23
### 번역
두 웹 페이지 URL을 입력받아 한 페이지에서 다른 페이지로 가는 링크 경로를 찾는 프로그램을 작성하시오. 적절한 탐색 전략은 무엇인가? 양방향 탐색은 좋은 생각인가? 검색 엔진을 이용해 선행자(predecessor) 함수를 구현할 수 있는가?

### 풀이
```python
from collections import deque
from urllib.parse import urljoin
import re, urllib.request

def links(url):
    try:
        html = urllib.request.urlopen(url, timeout=5).read().decode('utf-8', 'ignore')
    except Exception:
        return []
    return [urljoin(url, h).split('#')[0] for h in re.findall(r'href="([^"]+)"', html)]

def find_path(start, goal, max_nodes=10000):
    frontier, parent = deque([start]), {start: None}
    while frontier and len(parent) < max_nodes:
        u = frontier.popleft()
        for v in links(u):
            if v in parent: continue
            parent[v] = u
            if v == goal:
                path = [v]
                while parent[path[-1]]: path.append(parent[path[-1]])
                return path[::-1]
            frontier.append(v)
    return None
```

- **탐색 전략**: 웹 그래프는 분기 계수가 크고(페이지당 링크 수십~수백 개) 무한에 가까우므로 깊이 우선은 엉뚱한 방향으로 끝없이 빠질 수 있다. **너비 우선 그래프 탐색**(방문한 URL 기록)이 짧은 경로를 찾는 데 적합하다. 페이지 내용의 유사도(목표 페이지와 단어가 많이 겹치는 링크 우선)를 휴리스틱으로 쓰는 탐욕적 최선 우선 탐색도 실용적이다.
- **양방향 탐색**: 이론적으로는 $O(b^{d/2})$로 크게 이득이다. 하지만 역방향으로 가려면 “어떤 페이지가 이 페이지를 링크하는가”를 알아야 하는데, 웹 링크는 단방향이라 페이지 자체로는 알 수 없다. 선행자 함수를 구할 수 있을 때만 좋은 생각이다.
- **검색 엔진으로 선행자 함수 구현**: 일부 검색 엔진이 특정 URL로 링크하는 페이지를 찾는 기능(역링크 검색)을 제공했다면 가능하다. 다만 결과가 불완전하고(색인된 페이지만), 호출 횟수 제한이 있어 근사적인 선행자 함수다.

## 3.24
### 번역
[교재 참조: 진공청소기 세계 문제 정의]에 정의된 진공청소기 세계 문제를 생각하자.
1. 이 장에서 정의한 알고리즘 중 어느 것이 이 문제에 적합하겠는가? 알고리즘은 트리 탐색을 써야 하는가, 그래프 탐색을 써야 하는가?

3. 진공청소기 세계를 위한 탐색 에이전트를 만들고, 각 칸에 먼지가 있을 확률이 0.2인 $3\times 3$ 세계들에서 성능을 평가하시오. 적절한 교환 비율을 사용하여 성능 척도에 경로 비용뿐 아니라 탐색 비용도 포함하시오.
4. 가장 좋은 탐색 에이전트를, 먼지가 있으면 청소하고 없으면 무작위로 이동하는 단순 무작위 반사 에이전트와 비교하시오.
5. 세계가 $n \times n$으로 커지면 어떤 일이 일어날지 생각해 보시오. 탐색 에이전트와 반사 에이전트의 성능은 $n$에 따라 어떻게 변하는가?

### 풀이
1. 상태 공간이 유한하고 단계 비용이 모두 1이며, 행동을 되돌릴 수 있어(왼쪽 → 오른쪽) 반복 상태가 많다. **그래프 탐색**이어야 하고, 최적 해를 원하면 **너비 우선 탐색**(단위 비용) 또는 휴리스틱(예: 남은 먼지 수 + 가장 먼 먼지까지의 맨해튼 거리 같은 허용 가능한 값)을 쓰는 **A\***가 적합하다.
2. 칸을 (행, 열)로 두고 에이전트가 (1,1), 먼지가 (0,0), (0,1), (0,2)에 있다. 먼지 3칸을 모두 청소하려면 Suck 3번이 필요하고, 가운데에서 위쪽 줄 세 칸을 모두 방문하려면 최소 4번 이동해야 한다(위로 1번, 그다음 위쪽 줄 세 칸을 다 지나려면 한쪽 끝을 먼저 갔다가 반대쪽 끝까지 가야 하므로 3번). 따라서 최적 비용은 7이고, 최적 행동 열의 예는

   **Up, Suck, Left, Suck, Right, Right, Suck** (7단계)

   이다. (Up, Left, Suck, Right, Suck, Right, Suck 도 같은 비용 7의 최적 해다.)
3. **평가 방법**: 무작위 세계를 여러 개(예: 100개) 생성하고, 각 세계에서 에이전트가 처음에 A*로 계획을 세운 뒤 실행한다. 성능 = −(실행한 행동 수) − $\alpha$ × (탐색 중 확장한 노드 수). 교환 비율 $\alpha$는 예를 들어 “노드 1000개 확장 = 행동 1번” ($\alpha = 0.001$)처럼 컴퓨터의 계산 속도와 실제 행동 시간을 비교해 정한다. $3\times3$에서 먼지 확률 0.2면 평균 먼지 칸은 1.8개라 탐색이 매우 작아서, 탐색 비용은 거의 무시할 만하다.
4. **비교**: 무작위 반사 에이전트는 계획 비용이 없지만 먼지를 찾기 위해 헤매므로 평균 행동 수가 훨씬 많다. $3\times3$처럼 작은 세계에서는 탐색 에이전트가 거의 항상 낫다.
5. **$n\times n$으로 커지면**: 먼지가 있는 칸 수가 $k \approx 0.2n^2$이고, 최적 청소 순서 찾기는 외판원 문제처럼 상태 공간이 $n^2\cdot 2^{k}$로 지수적으로 커진다. 최적 탐색 에이전트의 탐색 비용이 폭발해 교환 비율을 반영한 성능이 급격히 나빠진다. 반사 에이전트는 계산 비용은 없지만 무작위 보행으로 모든 칸을 방문하는 시간이 대략 $O(n^2 \log n)$ 이상으로 늘어난다. 큰 $n$에서는 최적 대신 근사 계획(예: 가장 가까운 먼지로 탐욕적으로 이동, 또는 지그재그 순회)을 쓰는 에이전트가 가장 좋은 절충이 된다.

### 번역
다음 각 진술을 증명하거나 반례를 제시하시오.
1. 너비 우선 탐색은 균일 비용 탐색의 특수한 경우이다.
2. 깊이 우선 탐색은 최선 우선 트리 탐색의 특수한 경우이다.
3. 균일 비용 탐색은 A* 탐색의 특수한 경우이다.

3. **참.** A*에서 $h(n) = 0$으로 두면 $f(n) = g(n)$이므로 균일 비용 탐색과 같다. ($h=0$은 허용 가능하고 일관적이다.)

(트리 탐색으로 추적하면 2단계에서 Mehadia의 자식으로 Lugoj($g$=140, $f$=384)가 다시 생성되고, 3단계에서 이 노드가 먼저 확장되는 등 중복 노드가 추가로 나타난다. 최종 해는 같다.)

## 3.28
### 번역
때로는 어떤 문제에 대한 좋은 평가 함수는 없지만 좋은 비교 방법, 즉 두 노드 중 어느 쪽이 더 나은지를 어느 쪽에도 수치를 부여하지 않고 알려 주는 방법은 있다. 이것만으로 최선 우선 탐색을 하기에 충분함을 보이시오. 이 상황에서 A*에 해당하는 것이 있는가?

### 풀이
- 최선 우선 탐색이 평가 함수로 하는 일은 **프런티어에서 가장 좋은 노드를 고르는 것**뿐이다. 우선순위 큐(힙)는 원소 사이의 비교 연산만으로 구현할 수 있다. 따라서 비교 방법이 전순서(전이적이고 모든 쌍을 비교 가능)를 이루기만 하면, 수치 없이도 프런티어를 정렬해 가장 좋은 노드를 꺼낼 수 있다. 즉 최선 우선 탐색이 가능하다.
- **A\*에 해당하는 것**: A*는 $f(n) = g(n) + h(n)$이라는 *합*에 의존한다. 비교만으로는 경로 비용과 남은 비용 추정을 더할 수 없으므로, 일반적으로 A*를 그대로 흉내 낼 수 없다. 다만 비교 방법이 “노드 $n$을 지나는 최적 해의 비용”을 비교하는 것이라면(즉 $f$를 암묵적으로 비교한다면) 그 비교로 A*와 같은 순서를 얻을 수 있다. 최적성을 보장하려면 그 비교가 허용 가능성에 해당하는 조건(실제 비용을 과대평가하는 순서를 만들지 않음)을 만족해야 한다.

## 3.29
### 번역
[교재 참조: 그래프 탐색 버전의 A*]가, 허용 가능하지만 일관적이지 않은 $h(n)$ 함수를 사용할 때 최적이 아닌 해를 반환하는 상태 공간을 고안하시오.

### 풀이
상태 S(시작), A, B, G(목표). 간선과 비용:
- S → A: 1, S → B: 3, A → B: 1, B → G: 3

최적 경로는 S → A → B → G로 비용 5이다.

휴리스틱: $h(S)=0$, $h(A)=4$, $h(B)=1$, $h(G)=0$.
- **허용 가능**: $h^*(A) = 1+3 = 4 \ge 4$, $h^*(B) = 3 \ge 1$, $h^*(S) = 5 \ge 0$. ✓
- **일관적이지 않음**: $h(A) = 4 > c(A,B) + h(B) = 1 + 1 = 2$. ✗

**그래프 탐색 A\*의 동작**(이미 확장한 노드는 다시 열지 않음):
1. S 확장: A ($g$=1, $f$=5), B ($g$=3, $f$=4) 생성.
2. B 확장($f$=4가 가장 작음): G ($g$=6, $f$=6) 생성. B는 탐색 집합에 들어감.
3. A 확장($f$=5): 후속자 B ($g$=2)는 이미 탐색 집합에 있으므로 버려진다.
4. G 확장($f$=6): 비용 **6**인 해 S → B → G 반환.

최적 비용 5보다 나쁜 해를 반환한다. 일관성이 없으면 어떤 노드를 처음 확장할 때 그 노드까지의 최적 경로가 이미 발견되었다는 보장이 없기 때문이다.

## 3.30
### 번역
정확한 휴리스틱이 최악의 경우 탐색 시간을 줄여 주는 것은 아니다. 임의의 깊이 $d$에 대해, 깊이 $d$에 목표 노드가 있는 탐색 문제를 정의하고 $|h(n) - h^*(n)| \le O(\log h^*(n))$ 이면서도 $A^*$가 깊이 $d$ 미만의 모든 노드를 확장하게 되는 휴리스틱 함수를 작성하시오.

### 풀이
**문제 정의**: 깊이 $d$의 완전 이진 트리, 모든 간선 비용 1. 깊이 $d$의 잎 중 하나(맨 왼쪽)만 목표 G이다. 목표로 가는 경로 위에 있지 않은 노드(“곁가지 노드”)마다 G로 바로 가는 우회 간선을 하나 추가하고, 깊이 $k$의 곁가지 노드에서 그 비용을 $(d-k)+1$로 둔다. 그러면
- 경로 위 노드(깊이 $k$): $h^*(n) = d-k$, 최적 비용 $C^* = d$.
- 곁가지 노드(깊이 $k$): $h^*(n) = (d-k)+1$ (우회 간선 또는 그 자식의 우회 간선, 둘 다 같은 값).

**휴리스틱**: 경로 위 노드는 $h(n) = h^*(n) = d-k$, 곁가지 노드는 $h(n) = d-k-1$ (단 0 이상).
- 오차: 곁가지 노드에서 $|h - h^*| = 2$, 경로 위에서는 0. 상수 2는 $O(\log h^*(n))$ 이하이다(작은 $h^*$에서도 상수배로 덮인다). 또한 $h \le h^*$이므로 허용 가능하다.

**A\*의 동작**: 깊이 $k < d$인 곁가지 노드의 $f = k + (d-k-1) = d-1 < C^* = d$이다. A*는 $f < C^*$인 노드를 반드시 모두 확장하므로, 깊이 $d$ 미만의 모든 곁가지 노드를 확장한다. 경로 위 노드는 $f = d = C^*$이고 목표를 찾으려면 이들도 확장해야 한다. 따라서 깊이 $d$ 미만의 모든 노드, 즉 $2^d - 1$개를 확장한다. 휴리스틱이 상수 오차로 매우 정확한데도 확장 노드 수가 지수적이다. (우회 간선으로 생성된 G는 $g = d+1$이라 최적 해가 먼저 반환된다.)

## 3.31
### 번역
휴리스틱 경로 알고리즘 [Pohl, 1977]은 평가 함수가 $f(n) = (2-w)g(n) + wh(n)$인 최선 우선 탐색이다. $w$가 어떤 값일 때 이 알고리즘은 완전한가? $h$가 허용 가능하다고 가정할 때 어떤 값에서 최적인가? $w=0$, $w=1$, $w=2$일 때 각각 어떤 탐색을 수행하는가?

### 풀이
- **특수한 경우**
  - $w=0$: $f = 2g(n)$ → $g$ 순서로 확장하므로 **균일 비용 탐색**.
  - $w=1$: $f = g(n) + h(n)$ → **A\* 탐색**.
  - $w=2$: $f = 2h(n)$ → $h$만 보므로 **탐욕적 최선 우선 탐색**.
- **최적성**: $0 \le w < 2$일 때 $f$를 양수 $(2-w)$로 나누면 $f' = g + \frac{w}{2-w} h$와 같은 순서가 된다. 가중치 $\frac{w}{2-w} \le 1$, 즉 **$0 \le w \le 1$** 이면 $\frac{w}{2-w}h$도 허용 가능한 휴리스틱이므로 A*의 최적성 조건을 만족해 **최적**이다. $w > 1$이면 가중치가 1보다 커서 과대평가할 수 있으므로 최적이 보장되지 않는다(가중 A*).
- **완전성**: $0 \le w < 2$이면 $g$의 계수 $(2-w)$가 양수라서 경로 비용이 커지면 $f$도 결국 커지므로, 단계 비용이 양수의 하한 $\epsilon$ 이상이고 분기 계수가 유한하면 **완전하다**. $w = 2$(탐욕적 탐색)는 트리 탐색에서 무한 루프에 빠질 수 있어 일반적으로 완전하지 않다(유한 상태 공간의 그래프 탐색이라면 완전하다).

## 3.32
### 번역
[교재 참조: 2차원 격자 그림]에 나온 정규 2차원 격자의 무한(경계 없는) 버전을 생각하자. 시작 상태는 원점 (0,0)이고 목표 상태는 $(x,y)$이다.
1. 이 상태 공간의 분기 계수 $b$는 얼마인가?
2. 깊이 $k$ ($k>0$)에는 서로 다른 상태가 몇 개 있는가?
3. 너비 우선 트리 탐색이 확장하는 노드의 최대 개수는 얼마인가?
4. 너비 우선 그래프 탐색이 확장하는 노드의 최대 개수는 얼마인가?
5. 상태 $(u,v)$에 대해 $h = |u-x| + |v-y|$는 허용 가능한 휴리스틱인가? 설명하시오.
6. $h$를 쓰는 A* 그래프 탐색은 몇 개의 노드를 확장하는가?
7. 일부 연결을 제거해도 $h$는 허용 가능한가?
8. 인접하지 않은 상태 사이에 일부 연결을 추가해도 $h$는 허용 가능한가?

### 풀이
목표까지의 거리 $d = |x| + |y|$라고 두자.
1. 상하좌우 4방향이므로 **$b = 4$**.
2. 원점에서 맨해튼 거리가 정확히 $k$인 격자점은 **$4k$개**이다(마름모 둘레).
3. 트리 탐색은 같은 상태를 여러 번 만든다. 깊이 $d$의 목표를 찾기 전에 깊이 $d-1$까지의 모든 노드를 확장하므로 최대 $\sum_{i=0}^{d-1} 4^i = \frac{4^{d}-1}{3}$개 (목표와 같은 깊이의 노드까지 확장한다고 보면 $\frac{4^{d+1}-1}{3}$개).
4. 그래프 탐색은 각 상태를 한 번만 확장하므로, 거리 $d$ 이하의 상태 수 $1 + \sum_{k=1}^{d} 4k = 1 + 2d(d+1)$개가 최대다. 즉 $O(d^2)$.
5. **허용 가능하다.** 한 번의 이동은 $u$ 또는 $v$를 1만큼만 바꾸므로 맨해튼 거리를 한 번에 최대 1만큼 줄일 수 있다. 따라서 실제 최소 이동 수는 맨해튼 거리 이상이다. (실제로 장애물이 없으므로 정확히 같다, $h = h^*$.)
6. $h = h^*$이므로 최적 경로 위의 노드는 모두 $f = d$이고, 최적 경로를 벗어난 노드는 $f > d$이다. 최적 경로 위의 노드는 $(0,0)$에서 $(x,y)$까지의 직사각형 안 모든 점이다. 동점 처리에 따라 다르지만, 동점에서 $g$가 큰(목표에 가까운) 노드를 먼저 고르면 경로 하나를 따라 **$d+1$개**만 확장하고, 최악의 경우 직사각형 안의 모든 점 **$(|x|+1)(|y|+1)$개**를 확장한다.
7. **허용 가능하다.** 연결을 제거하면 경로가 길어질 수만 있으므로 $h^*$는 커지거나 같고, $h$는 여전히 과대평가하지 않는다.
8. **허용 가능하지 않을 수 있다.** 멀리 떨어진 상태를 잇는 연결(지름길)이 생기면 실제 비용이 맨해튼 거리보다 작아질 수 있어 $h$가 과대평가한다.

## 3.33
### 번역
$n$대의 차량이 $n\times n$ 격자의 $(1,1)$부터 $(n,1)$까지의 칸(즉 맨 아래 줄)을 차지하고 있다. 차량들은 맨 위 줄로 옮겨져야 하는데 순서가 뒤바뀌어야 한다. 즉 $(i,1)$에서 시작하는 차량 $i$는 $(n-i+1,n)$에 도착해야 한다. 매 시간 단계마다 $n$대의 차량 각각은 위, 아래, 왼쪽, 오른쪽으로 한 칸 움직이거나 그대로 있을 수 있다. 단, 어떤 차량이 그대로 있으면 인접한 다른 차량 하나(둘 이상은 안 됨)가 그 차량을 뛰어넘을 수 있다. 두 차량은 같은 칸을 차지할 수 없다.
1. 상태 공간의 크기를 $n$의 함수로 계산하시오.
2. 분기 계수를 $n$의 함수로 계산하시오.
3. 차량 $i$가 $(x_i,y_i)$에 있다고 하자. 격자에 다른 차량이 없다고 가정할 때, 목표 위치 $(n-i+1,n)$까지 필요한 이동 수에 대한 자명하지 않은 허용 가능한 휴리스틱 $h_i$를 작성하시오.
4. $n$대의 차량을 모두 목적지로 옮기는 문제에 대해 다음 휴리스틱 중 허용 가능한 것은 무엇인가? 설명하시오.
   1. $\sum_{i= 1}^{n} h_i$
   2. $\max\{h_1,\ldots,h_n\}$
   3. $\min\{h_1,\ldots,h_n\}$

### 풀이
1. 차량은 서로 구별되므로, $n^2$개의 칸에 $n$대를 서로 다른 칸에 배치하는 경우의 수는
   $$n^2(n^2-1)\cdots(n^2-n+1) = \frac{(n^2)!}{(n^2-n)!} \approx n^{2n}.$$
2. 각 차량은 최대 5가지 행동(상하좌우, 정지)을 할 수 있으므로 분기 계수는 최대 **$5^n$**이다(뛰어넘기는 이동 방향 중 하나로 볼 수 있다). 충돌이나 격자 경계 때문에 실제로는 더 적다.
3. 다른 차량이 없으면 뛰어넘기가 불가능하므로 한 번에 한 칸만 움직인다. 따라서 맨해튼 거리
   $$h_i = |(n-i+1) - x_i| + |n - y_i|$$
   는 허용 가능하다(사실 정확한 값이다).
4. 모든 차량이 **동시에** 움직이므로, 전체 문제의 비용(시간 단계 수)은 가장 오래 걸리는 차량이 결정한다.
   - (i) $\sum h_i$: **허용 가능하지 않다.** 예를 들어 각 차량이 1칸씩 가야 하면 합은 $n$인데 한 단계면 끝난다.
   - (ii) $\max h_i$: **허용 가능하다.** 어떤 차량도 자신의 $h_i$보다 빨리 도착할 수 없다. 단, 다른 차량이 있으면 뛰어넘기로 한 단계에 2칸 갈 수 있으므로 엄밀하게는 $h_i$ 대신 $\lceil h_i/2 \rceil$를 써야 안전하다. 문제의 의도(뛰어넘기 무시)에서는 $\max h_i$가 허용 가능하다.
   - (iii) $\min h_i$: **허용 가능하다.** $\min \le \max \le$ 실제 비용이다. 다만 $\max$보다 덜 정확하다.

## 3.34
### 번역
제한 없는(무한) 체스판에서 $k$개의 나이트를 $k$개의 시작 칸 $s_1,\ldots,s_k$에서 $k$개의 목표 칸 $g_1,\ldots,g_k$로 옮기는 문제를 생각하자. 두 나이트는 같은 시각에 같은 칸에 착지할 수 없다. 각 행동은 최대 $k$개의 나이트를 동시에 움직이는 것으로 이루어진다. 가능한 한 적은 수의 행동으로 이동을 마치고 싶다.
1. 이 상태 공간의 최대 분기 계수를 $k$의 함수로 표현하면 얼마인가?
2. $h_i$가 나이트 $i$ 하나만 목표 $g_i$로 옮기는 문제에 대한 허용 가능한 휴리스틱이라고 하자. 다음 중 $k$-나이트 문제에 대해 허용 가능한 휴리스틱은 무엇인가? 그중 가장 좋은 것은 무엇인가?
   1. $\min\{h_1,\ldots,h_k\}$
   2. $\max\{h_1,\ldots,h_k\}$
   3. $\sum_{i= 1}^{k} h_i$
3. 한 번에 나이트 하나만 움직일 수 있는 경우에 대해 (b)를 반복하시오.

### 풀이
1. 각 나이트는 8가지 이동 또는 정지(9가지)를 할 수 있으므로 $9^k$가지 조합이다. 모두 정지하는 것은 의미 없으므로 최대 분기 계수는 **$9^k - 1$**이다.
2. 나이트들이 동시에 움직이므로 전체 행동 수는 적어도 가장 오래 걸리는 나이트의 이동 수 이상이다.
   - (i) $\min h_i$: 허용 가능.
   - (ii) $\max h_i$: 허용 가능. 각 $h_i$가 나이트 $i$의 실제 필요 이동 수 이하이고, 전체 비용은 그중 최댓값 이상이기 때문이다.
   - (iii) $\sum h_i$: 허용 가능하지 않음. 나이트 $k$개가 각각 1번씩 움직이면 되는 경우 합은 $k$이지만 실제로는 1번의 행동으로 끝난다.
   - **가장 좋은 것은 $\max$**이다(허용 가능한 것 중 값이 가장 크므로 $\min$을 지배한다).
3. 한 번에 하나씩만 움직이면 전체 행동 수 = 각 나이트의 이동 수의 합이다.
   - $\min$, $\max$, $\sum$ **모두 허용 가능**하다. 실제 비용 $\ge \sum (\text{각 나이트의 실제 이동 수}) \ge \sum h_i \ge \max h_i \ge \min h_i$.
   - **가장 좋은 것은 $\sum h_i$**이다.

## 3.35
### 번역
[교재: I-to-F]에서 직선 거리 휴리스틱이 이아시(Iasi)에서 파가라시(Fagaras)로 가는 문제에서 탐욕적 최선 우선 탐색을 잘못된 길로 이끈다는 것을 보았다. 그러나 반대 문제, 즉 파가라시에서 이아시로 가는 문제에서는 이 휴리스틱이 완벽하게 동작한다. 양쪽 방향 모두에서 휴리스틱이 오도하는 문제가 있는가?

### 풀이
**있다.** 직선 거리로는 가깝지만 도로로는 연결되지 않은 막다른 길을 양쪽 끝 근처에 하나씩 두면 된다.

예: 도시 A와 B가 직선으로는 멀리 떨어져 있고, 둘 사이의 유일한 도로는 크게 우회하는 길이다. 여기에 A 근처에 B 쪽으로 뻗은 막다른 길(도시 A′, B에 직선으로 매우 가까움, A와만 연결)을 두고, B 근처에 A 쪽으로 뻗은 막다른 길(도시 B′, A에 직선으로 매우 가까움, B와만 연결)을 둔다.
- A → B: 탐욕적 탐색은 B에 가까워 보이는 A′로 먼저 간다. 막다른 길이라 되돌아와야 한다(트리 탐색이면 A′ ↔ A를 오가며 무한 루프에 빠질 수도 있다).
- B → A: 마찬가지로 B′로 먼저 빠진다.

따라서 양방향 모두에서 휴리스틱이 오도한다. 이아시–파가라시 예에서 문제가 된 니암츠(Neamt) 같은 막다른 길을 양쪽에 둔 것과 같은 구조다.

## 3.36
### 번역
8-퍼즐을 위해 때때로 과대평가하는 휴리스틱 함수를 고안하고, 그것이 특정 문제에서 최적이 아닌 해로 이어질 수 있음을 보이시오. (원한다면 컴퓨터의 도움을 받아도 된다.) $h$가 $c$보다 더 크게 과대평가하는 일이 결코 없다면, $h$를 쓰는 A*가 반환하는 해의 비용이 최적 해의 비용보다 최대 $c$만큼만 크다는 것을 증명하시오.

### 풀이
**과대평가하는 휴리스틱의 예**: $h(n) = 2 \times$ (맨해튼 거리), 또는 $h(n) = h_2(n) + $ (제자리가 아닌 타일 수)$\times 2$. 이런 휴리스틱을 쓰는 A*는 목표에 가까워 보이는 경로를 지나치게 선호하므로, 실제로는 한두 수 더 긴 경로를 반환하는 시작 상태를 쉽게 찾을 수 있다. (컴퓨터로 무작위 시작 상태들에 대해 이 A*와 맨해튼 거리 A*의 해 길이를 비교해, 차이가 나는 상태를 하나 찾아 제시하면 된다.)

**증명**: 모든 노드에서 $h(n) \le h^*(n) + c$라고 하자. 최적 해 비용을 $C^*$라 하고, A*가 비용 $C > C^* + c$인 목표 $G_2$를 반환한다고 가정하자.

$G_2$가 선택되는 순간, 최적 경로 위의 어떤 노드 $n$이 프런티어에 있다(분리 속성, 3.16). 그 노드에 대해
$$f(n) = g(n) + h(n) \le g(n) + h^*(n) + c = C^* + c.$$
(최적 경로 위에 있으므로 $g(n) + h^*(n) = C^*$.)

한편 $G_2$는 목표이므로 $h(G_2) = 0$이라 하면 $f(G_2) = g(G_2) = C > C^* + c \ge f(n)$. A*는 $f$가 가장 작은 노드를 먼저 고르므로 $G_2$보다 $n$을 먼저 확장해야 한다. 이는 $G_2$가 선택되었다는 가정에 모순이다. 따라서 반환된 해의 비용은 $C \le C^* + c$이다. ∎ (목표에서 $h(G)=0$이라는 가정이 필요하며, 그렇지 않더라도 $h(G) \ge 0$이면 $g(G_2) \le f(G_2)$로 같은 결론이 나온다.)

## 3.37
### 번역
휴리스틱이 일관적이면 반드시 허용 가능함을 증명하시오. 허용 가능하지만 일관적이지 않은 휴리스틱을 만드시오.

### 풀이
**증명**: 일관성은 모든 노드 $n$과 그 후속자 $n'$에 대해 $h(n) \le c(n,a,n') + h(n')$, 그리고 목표 $G$에서 $h(G)=0$인 것이다. 노드 $n$에서 가장 가까운 목표까지의 최적 경로 $n = n_0, n_1, \dots, n_k = G$에 대해, $k$에 대한 귀납법을 쓴다.
- $k=0$: $n$이 목표이므로 $h(n) = 0 = h^*(n)$.
- $k \ge 1$: $n_1$에서 목표까지의 최적 경로 길이는 $k-1$이므로 귀납 가정에 의해 $h(n_1) \le h^*(n_1)$. 그러면
  $$h(n) \le c(n, n_1) + h(n_1) \le c(n, n_1) + h^*(n_1) = h^*(n).$$
  (마지막 등호는 $n_1$이 $n$의 최적 경로 위에 있기 때문.)

따라서 모든 노드에서 $h(n) \le h^*(n)$, 즉 허용 가능하다. 목표에 도달할 수 없는 노드는 $h^*(n) = \infty$라 자명하다. ∎

**허용 가능하지만 일관적이지 않은 예**: 3.29의 예. $h(A)=4$, $h(B)=1$, $c(A,B)=1$이고 $h^*(A)=4$, $h^*(B)=3$이면 허용 가능하지만 $h(A) = 4 > 1 + 1 = c(A,B) + h(B)$라 일관적이지 않다. 8-퍼즐에서도 예를 들 수 있다. 맨해튼 거리를 쓰되 일부 상태에서만 0으로 바꾸면(예: 무작위로 절반의 상태에서 $h=0$), 여전히 과대평가하지 않지만 이웃한 두 상태 사이에서 $h$가 2 이상 뛰므로 일관성이 깨진다.

## 3.38
### 번역
외판원 문제(TSP)는 최소 신장 트리(MST) 휴리스틱으로 풀 수 있다. 이 휴리스틱은 부분 경로가 이미 만들어졌을 때 순회를 완성하는 비용을 추정한다. 도시 집합의 MST 비용은 모든 도시를 연결하는 트리들 중 연결 비용의 합이 가장 작은 값이다.
1. 이 휴리스틱을 TSP의 완화된(relaxed) 버전으로부터 유도하는 방법을 보이시오.
2. MST 휴리스틱이 직선 거리를 지배(dominate)함을 보이시오.
3. 도시가 단위 정사각형 안의 무작위 점으로 표현되는 TSP 인스턴스 생성기를 작성하시오.
4. 문헌에서 MST를 구성하는 효율적인 알고리즘을 찾아, A* 그래프 탐색과 함께 사용해 TSP 인스턴스를 푸시오.

### 풀이
1. **완화 문제로부터 유도**: TSP의 해는 아직 방문하지 않은 도시들(그리고 현재 도시와 출발 도시)을 모두 지나는 *경로*(순회의 나머지 부분)이다. 경로는 특별한 형태의 신장 트리(가지가 없는 트리)이다. “경로여야 한다”는 조건을 “연결된 트리이기만 하면 된다”로 완화하면, 완화 문제의 최적 해는 그 도시들의 MST이다. 완화 문제의 최적 비용은 원래 문제의 최적 비용 이하이므로 MST 비용은 허용 가능한 휴리스틱이다(그리고 일관적이다).
2. **직선 거리 지배**: 직선 거리 휴리스틱을 “현재 도시에서 남은 도시 중 하나(예: 출발 도시)까지의 직선 거리”로 정의하자. MST는 현재 도시와 그 도시를 포함한 모든 도시를 연결하므로, MST 안에는 두 도시를 잇는 경로가 있다. 삼각 부등식에 의해 그 경로의 길이는 두 도시 사이의 직선 거리 이상이고, MST 전체 비용은 그 경로 길이 이상이다. 따라서 모든 상태에서 $h_{\text{MST}} \ge h_{\text{SLD}}$, 즉 지배한다.
3. **생성기**
   ```python
   import random, math
   def random_tsp(n, seed=None):
       rng = random.Random(seed)
       pts = [(rng.random(), rng.random()) for _ in range(n)]
       dist = [[math.dist(p, q) for q in pts] for p in pts]
       return pts, dist
   ```
4. **MST 알고리즘과 A\***: 완전 그래프에서는 프림(Prim) 알고리즘이 $O(n^2)$로 적합하다(희소 그래프라면 크루스칼 알고리즘 $O(E\log E)$).
   ```python
   import heapq
   def mst_cost(nodes, dist):
       nodes = list(nodes)
       if len(nodes) <= 1: return 0.0
       best = {v: dist[nodes[0]][v] for v in nodes[1:]}; total = 0.0
       while best:
           v = min(best, key=best.get); total += best.pop(v)
           for u in best: best[u] = min(best[u], dist[v][u])
       return total

   def tsp_astar(dist):
       n = len(dist); start = (0, frozenset([0]))
       h = lambda cur, vis: mst_cost([c for c in range(n) if c not in vis] + [cur, 0], dist)
       frontier = [(h(0, start[1]), 0.0, 0, start[1], [0])]; closed = set()
       while frontier:
           f, g, cur, vis, path = heapq.heappop(frontier)
           if len(vis) == n and cur == 0 and len(path) > 1: return g, path
           if (cur, vis) in closed: continue
           closed.add((cur, vis))
           nexts = [c for c in range(n) if c not in vis] or ([0] if cur != 0 else [])
           for c in nexts:
               v2 = vis | {c}; g2 = g + dist[cur][c]
               heapq.heappush(frontier, (g2 + (0 if c == 0 else h(c, v2)), g2, c, v2, path + [c]))
   ```
   상태 수가 $n\cdot 2^n$이라 $n$이 15~20을 넘으면 메모리와 시간이 급격히 늘어난다. MST 휴리스틱은 직선 거리보다 훨씬 많은 노드를 가지치기한다.

## 3.39
### 번역
[교재: Gaschnig-h-page]에서 칸 B가 비어 있으면 타일이 칸 A에서 칸 B로 이동할 수 있는 8-퍼즐의 완화 문제를 정의했다. 이 문제의 정확한 해가 가슈니그(Gaschnig)의 휴리스틱 [Gaschnig, 1979]을 정의한다. 가슈니그의 휴리스틱이 왜 적어도 $h_1$(제자리에 있지 않은 타일 수)만큼 정확한지 설명하고, $h_1$과 $h_2$(맨해튼 거리) 모두보다 더 정확한 경우를 보이시오. 가슈니그의 휴리스틱을 효율적으로 계산하는 방법을 설명하시오.

### 풀이
**$h_1$ 이상인 이유**: 완화 문제에서도 제자리에 있지 않은 타일은 각각 적어도 한 번은 움직여야 목표 위치에 갈 수 있다. 한 번의 이동은 타일 하나만 옮기므로 이동 수 ≥ 제자리가 아닌 타일 수 = $h_1$. 따라서 $h_{\text{G}} \ge h_1$이다. 또 완화 문제이므로 실제 비용 이하(허용 가능)이다.

**$h_1$, $h_2$보다 더 정확한 경우**: 빈칸은 이미 목표 위치에 있고, 서로 이웃한 타일 두 개씩이 자리를 맞바꾼 쌍이 두 개 있다고 하자(예: 목표에서 1↔2, 4↔7을 바꾼 배치).
- $h_1 = 4$ (잘못된 타일 4개).
- $h_2 = 4$ (각 타일이 1칸씩 떨어짐).
- 가슈니그: 빈칸이 제자리이므로 맞바뀐 쌍마다 “타일 하나를 빈칸으로 옮김 → 다른 타일을 제자리로 → 첫 타일을 제자리로”의 3번이 든다. 두 쌍이면 $h_{\text{G}} = 6$.

따라서 $h_{\text{G}} = 6 > h_1 = h_2 = 4$이다. (실제 최소 이동 수는 이보다 더 크다.)

**효율적 계산**: 시뮬레이션 대신 사이클 구조로 바로 계산할 수 있다. 현재 배치를 “각 칸 → 그 칸에 있는 타일의 목표 칸”이라는 순열로 보고 사이클로 분해한다.
- 빈칸을 포함한 사이클(길이 $L_0$): 빈칸이 지나가며 $L_0 - 1$번의 이동으로 해결.
- 빈칸을 포함하지 않는 길이 $L \ge 2$인 사이클 각각: 빈칸을 그 사이클로 끌어들이는 이동 1번이 추가되어 $L + 1$번.
- 따라서 $h_{\text{G}} = (L_0 - 1) + \sum_{\text{기타 사이클}} (L+1)$ (빈칸이 제자리면 $L_0 = 1$). 이는 $O(n)$에 계산된다. (그리디 시뮬레이션 — 빈칸이 목표 위치가 아니면 그 위치의 타일을 빈칸으로 옮기고, 빈칸이 제자리면 아무 잘못된 타일을 빈칸으로 옮김 — 도 최적 값을 준다.)

## 3.40
### 번역
8-퍼즐을 위한 두 가지 단순한 휴리스틱, 맨해튼 거리와 제자리가 아닌 타일 수를 소개했다. 문헌의 여러 휴리스틱은 이보다 개선되었다고 주장한다. 예를 들어 [Nilsson, 1971], [Mostow & Prieditis, 1989], [Hansson 외, 1992]를 보라. 이 휴리스틱들을 구현하고 그 결과 알고리즘들의 성능을 비교하여 이 주장들을 검증하시오.

### 풀이
**비교할 휴리스틱의 예**
- $h_1$: 제자리가 아닌 타일 수.
- $h_2$: 맨해튼 거리.
- **닐슨의 순서 점수(sequence score)**: $h_2 + 3\times S$, $S$는 가장자리를 따라 시계 방향으로 다음 타일이 올바르지 않을 때마다 2점, 가운데 칸이 비어 있지 않으면 1점. **허용 가능하지 않다**(과대평가). 빠르지만 최적 해를 보장하지 않는다.
- **선형 충돌(linear conflict, 한손 외 1992)**: $h_2 + 2 \times$ (같은 행 또는 열에 있고 둘 다 그 행/열이 목표인데 순서가 뒤바뀐 타일 쌍의 수). 허용 가능하며 $h_2$를 지배한다.
- **가슈니그 휴리스틱(3.39)**, **완화 문제 자동 생성(Mostow & Prieditis)** 으로 얻은 휴리스틱, 패턴 데이터베이스(교재 3.6.3절) 등.

**실험 방법**
```python
GOAL = (1, 2, 3, 4, 5, 6, 7, 8, 0)
POS = {t: divmod(i, 3) for i, t in enumerate(GOAL)}      # 타일 → 목표 (행, 열)

def manhattan(s):
    return sum(abs(r - POS[t][0]) + abs(c - POS[t][1])
               for i, t in enumerate(s) if t for r, c in [divmod(i, 3)])

def linear_conflict(s):
    h = manhattan(s)
    for k in range(3):
        row = [s[3 * k + c] for c in range(3)]                       # k번째 행
        col = [s[3 * r + k] for r in range(3)]                       # k번째 열
        in_row = [POS[t][1] for t in row if t and POS[t][0] == k]    # 목표도 이 행인 타일의 목표 열
        in_col = [POS[t][0] for t in col if t and POS[t][1] == k]    # 목표도 이 열인 타일의 목표 행
        for line in (in_row, in_col):
            h += 2 * sum(line[i] > line[j] for i in range(len(line)) for j in range(i + 1, len(line)))
    return h
```
(엄밀한 선형 충돌은 한 줄 안에서 충돌을 없애는 데 필요한 최소 타일 수를 세지만, 위처럼 뒤바뀐 쌍마다 2를 더하면 3×3에서 과대평가할 수 있으므로, 실험에서는 줄마다 “충돌 그래프에서 제거해야 할 최소 타일 수 × 2”로 계산해야 허용 가능성이 유지된다.)
- 풀 수 있는 무작위 시작 상태 100~1000개를 해 길이별로 나눠 생성한다.
- 각 휴리스틱으로 A*를 실행해 확장 노드 수, 실행 시간, 해 길이를 기록하고, 교재 그림 3.29처럼 **유효 분기 계수** $b^*$를 계산해 표로 비교한다.

**예상되는 결론**: 허용 가능한 휴리스틱 사이에서는 지배 관계대로 $h_1 < h_2 <$ 선형 충돌 순으로 확장 노드가 줄어든다. 다만 휴리스틱 계산 비용이 커지면 노드당 시간이 늘어나므로, 실행 시간 기준으로는 이득이 줄어든다. 닐슨의 휴리스틱은 노드 수가 가장 적을 수 있지만 해가 최적이 아닌 경우가 생긴다. 따라서 “개선되었다”는 주장은 확장 노드 수, 실행 시간, 해의 최적성 중 무엇을 기준으로 하느냐에 따라 달라진다는 점을 보고서에 밝혀야 한다.
