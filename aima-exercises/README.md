# AIMA 연습문제 (1~3장)

[aimacode/aima-exercises](https://github.com/aimacode/aima-exercises) (커밋 `137be53`)에서 가져온 1~3장 연습문제 원문입니다.
웹 버전: https://aimacode.github.io/aima-exercises/

| 장 | 폴더 | 문제 수 |
|---|---|---|
| 1장 Introduction | `1-Introduction/exercises/` | 20 |
| 2장 Intelligent Agent | `2-Intelligent-Agent/exercises/` | 16 |
| 3장 Solving Problems By Searching | `3-Solving-Problems-By-Searching/exercises/` | 40 |

각 문제는 `ex_번호/question.md`에 있습니다. 풀이는 포함되어 있지 않습니다.
문제에서 참조하는 그림은 `figures/`에 함께 넣어 두었습니다.

원본 라이선스: `LICENSE.md` (MIT)

## 학습 노트 앱

`app/aima-study.html`은 위 76문제를 한 페이지에 담은 학습 도구입니다.
claude.ai(또는 Claude 앱)의 Artifact로 열면 문제마다 한국어 번역, 해설, 모범 풀이,
내 답안 채점, 추가 질문을 Claude에게 요청할 수 있습니다. 결과는 브라우저에 저장됩니다.
일반 브라우저로 열면 원문만 볼 수 있습니다.
