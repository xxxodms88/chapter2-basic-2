# C 백지 연습장

프로그래밍 및 실습2 (C언어, 1~5장) 시험 대비용 공부 사이트입니다. `index.html` 파일 하나로 동작하며, 브라우저에서 열기만 하면 됩니다.

## 공부 방식

- **개념 빈칸**: 강의안의 핵심 문장 76개를 빈칸 채우기로 풉니다.
- **코드 빈칸**: 강의안 예제 43개 코드의 빈칸에 코드를 직접 입력합니다.
- **코드 백지 테스트**: 문제 설명과 실행 결과만 보고 전체 코드를 처음부터 작성하면, 정답과 구문 단위로 비교해서 줄마다 ○ / △ / ✕로 채점합니다.
  - 공백, 줄바꿈, 주석, 중괄호 위치, `_CRT_SECURE_NO_WARNINGS`, `scanf_s`/`scanf`, `main()`/`main(void)` 차이는 무시합니다.
  - "printf 안내 문구 무시" 옵션을 켜면 `%d`, `\n` 같은 형식만 채점합니다.
- **출력 예측**: 코드를 보고 실행 결과를 적습니다.

작성 중인 답안과 진도는 브라우저(localStorage)에 저장됩니다.

## 범위

1장 C언어 소개 · 2장 프로그램 작성 과정 · 3장 C프로그램 구성요소 · 4장 변수와 자료형 · 5장 수식과 연산자
