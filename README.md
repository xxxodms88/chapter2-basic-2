# C 백지 연습장

프로그래밍 및 실습2 (C언어, 1~9장) 시험 대비용 공부 사이트입니다. `index.html`과 C 실행기 `picoc-worker.js`로 이루어져 있습니다.

코드 실행(▶ 실행, 테스트 채점)은 웹 주소로 열었을 때만 동작합니다(예: GitHub Pages, `python -m http.server`). 파일을 더블클릭해서 열면 브라우저가 Web Worker를 막아서 실행만 빠지고 나머지는 그대로 쓸 수 있습니다.

## 공부 방식

- **이론 정리**: 장별 핵심 개념, 표, 자주 하는 실수를 정리했습니다.
- **코드 정리**: 장별 핵심 문법 패턴과 모든 예제의 정답 코드를 모았고, 키워드로 검색할 수 있습니다.
- **함수 퀴즈 (44문제)**: 시험처럼 main 함수가 주어지고 핵심 함수를 직접 작성합니다. 작년 기출(Quiz01 수열의 합, 중간고사 ln 근사)과 6~9장 예상 문제가 있고, 테스트 케이스를 실제로 실행해서 채점합니다.
- **개념 빈칸**: 강의안의 핵심 문장 153개를 빈칸 채우기로 풉니다.
- **코드 빈칸**: 강의안 예제와 변형 문제 139개 코드의 빈칸에 코드를 직접 입력합니다.
- **코드 백지 테스트**: 문제 설명과 실행 결과만 보고 전체 코드를 처음부터 작성하면, 정답과 구문 단위로 비교해서 줄마다 ○ / △ / ✕로 채점합니다.
  - 공백, 줄바꿈, 주석, 중괄호 위치, `_CRT_SECURE_NO_WARNINGS`, `scanf_s`/`scanf`, `main()`/`main(void)` 차이는 무시합니다.
  - "printf 안내 문구 무시" 옵션을 켜면 `%d`, `\n` 같은 형식만 채점합니다.
- **출력 예측 (60문제)**: 코드를 보고 실행 결과를 적습니다.

코드 빈칸, 백지 테스트, 출력 예측에서는 "변형 문제만"을 눌러 강의안 문제를 바꿔 만든 문제만 따로 풀 수 있습니다.

작성 중인 답안과 진도는 브라우저(localStorage)에 저장됩니다.

## 편집기

코드 작성 칸은 VS Code처럼 동작합니다(CodeMirror 5): 줄 번호, 문법 색, 괄호 자동 닫기, 자동 들여쓰기, 자동완성(Ctrl+Space), Ctrl+/ 주석, Alt+↑↓ 줄 이동, Ctrl+Enter 실행. 아래 터미널 패널에서 입력(stdin)을 넣고 결과를 봅니다.

C 실행기는 [picoc](https://gitlab.com/zsaleeba/picoc)를 WebAssembly로 컴파일한 [picoc-js](https://www.npmjs.com/package/picoc-js) 1.0.12(BSD)를 Web Worker용으로 조금 고친 것입니다. 콤마 연산자, stdarg.h, 블록 안 같은 이름 재선언은 지원하지 않고 float는 double로 처리됩니다.
