# C 백지 연습장

프로그래밍 및 실습2 (C언어, 1~8장) 시험 대비용 공부 사이트입니다. `index.html` 파일 하나로 동작하며, 브라우저에서 열기만 하면 됩니다.

## 공부 방식

- **이론 정리**: 장별 핵심 개념, 표, 자주 하는 실수를 정리했습니다.
- **코드 정리**: 장별 핵심 문법 패턴과 모든 예제의 정답 코드를 모았고, 키워드로 검색할 수 있습니다.
- **개념 빈칸**: 강의안의 핵심 문장 153개를 빈칸 채우기로 풉니다.
- **코드 빈칸**: 강의안 예제와 변형 문제 139개 코드의 빈칸에 코드를 직접 입력합니다.
- **코드 백지 테스트**: 문제 설명과 실행 결과만 보고 전체 코드를 처음부터 작성하면, 정답과 구문 단위로 비교해서 줄마다 ○ / △ / ✕로 채점합니다.
  - 공백, 줄바꿈, 주석, 중괄호 위치, `_CRT_SECURE_NO_WARNINGS`, `scanf_s`/`scanf`, `main()`/`main(void)` 차이는 무시합니다.
  - "printf 안내 문구 무시" 옵션을 켜면 `%d`, `\n` 같은 형식만 채점합니다.
- **출력 예측 (60문제)**: 코드를 보고 실행 결과를 적습니다.

코드 빈칸, 백지 테스트, 출력 예측에서는 "변형 문제만"을 눌러 강의안 문제를 바꿔 만든 문제만 따로 풀 수 있습니다.

작성 중인 답안과 진도는 브라우저(localStorage)에 저장됩니다.
